Log Extractor — десктопное приложение для извлечения, фильтрации и анализа логов из файлов в формате JSON Lines. Утилита предоставляет графический интерфейс для работы с логами Directum RX.


СКАЧАТЬ
-------

Готовый exe для Windows (Python не нужен) — на странице релизов:
https://github.com/Dgecon/UtilityForLogExtract/releases/latest


ВОЗМОЖНОСТИ
-----------

Основные функции:
  - Извлечение логов из одного или нескольких файлов одновременно
  - Поддержка rotated logs (файлы с индексами: *.0.log, *.1.log, *.log)
  - Автоматическая хронологическая сортировка записей
  - Парсинг JSON-строк с внутренней и внешней временной меткой
  - Цветовая подсветка записей по уровням логов

Фильтрация:
  - По времени: указание начальной и конечной даты и времени
  - По уровням: DEBUG, INFO, WARN, ERROR (выбор чекбоксами)
  - Пресеты: «Конвертация» и «Заполнение доп. полей» (выбор в шапке окна)
  - По источнику: только записи Logger (сообщения прикладного кода)
  - По содержанию: только ключевые записи выбранного пресета
  - По тексту: поиск подстроки по всей записи — время, уровень,
    сообщение, логгер, trace id. Не зависит от регистра, количества
    пробелов и «ё»/«е»; строка, скопированная из таблицы, находит саму себя

Экспорт данных:
  - Сохранение отфильтрованных записей в новый файл
  - Копирование отдельных строк или всех записей в буфер обмена
  - Копирование сводки выборки: время первой и последней записи
    (ГГГГ-ММ-ДД чч:мм:сс) и количество найденных записей

ИСПОЛЬЗОВАНИЕ
-------------

Запуск приложения:
  python "Log(Ex)Tractor.py"

Порядок работы:
  1. Пресет: выберите в шапке окна «Конвертация» или «Заполнение доп. полей»
  2. Выбор файлов: нажмите «Обзор…» и выберите один или несколько .log файлов
  3. Диапазон времени: укажите начальную и конечную дату и время
     (формат: YYYY-MM-DD HH:MM:SS; по умолчанию — сегодняшний день)
  4. Уровни логов: отметьте нужные уровни (DEBUG, INFO, WARN, ERROR)
  5. Дополнительные фильтры:
       - «Только Logger» — только записи с "lg": "Logger" (прикладной код),
         без служебных записей платформы (RabbitMQ, REST, блокировки и т.п.)
       - «🔑 Только ключевые записи» — только ключевые сообщения пресета
  6. Текстовый фильтр: введите или вставьте подстроку для поиска
  7. Извлечение: нажмите «▶ Извлечь» или Enter в поле фильтра
  8. Сохранение: нажмите «💾 Сохранить» для экспорта результатов в файл

Если ничего не найдено — проверьте диапазон дат (по умолчанию стоит
сегодняшний день), пресет и галки «Только …»: подсказка появится в строке статуса.

Кнопки в строке статуса (копируют в буфер обмена):
  - «Начало»    — дата и время первой записи выборки (ГГГГ-ММ-ДД чч:мм:сс)
  - «Кол-во»    — количество найденных записей
  - «Окончание» — дата и время последней записи выборки (ГГГГ-ММ-ДД чч:мм:сс)

Таблица:
  - ПКМ — контекстное меню
  - «Копировать строку» — копирует выделенные строки
  - «Копировать всё» — копирует все отфильтрованные записи

Поля ввода (фильтр, даты, путь к файлам):
  - Ctrl+V / Ctrl+C / Ctrl+X / Ctrl+A — работают в любой раскладке
  - Shift+Insert — вставка
  - ПКМ — меню: Вырезать / Копировать / Вставить / Выделить всё / Очистить
  - Вставка заменяет выделенный текст, переводы строк превращаются в пробелы


ПРЕСЕТЫ
-------

«Конвертация» — ключевые сообщения:
  - "Запущена постановка в очередь конвертации писем в docx"
  - "Найдено писем для постановки в очередь:"
  - "Постановка в очередь завершена. Всего"
  - Сообщения, начинающиеся с "ConvertOnEmail:"

«Заполнение доп. полей» — ключевые сообщения:
  - Сообщения, начинающиеся с "Заполнение доп. полей:"
    (запуск, остаток, прогресс постановки в очередь, ошибки)
  - Сообщения, начинающиеся с "FillOneMailExtraFields:" (по каждому письму)

Новый пресет добавляется записью в словарь PRESETS в начале
Log(Ex)Tractor.py: логгер, подстроки (contains) и префиксы (startswith)
ключевых сообщений в нижнем регистре, подпись для шапки (subtitle).


СБОРКА EXE
----------

Вручную (на Windows):
  pip install pyinstaller
  pyinstaller --onefile --windowed --name LogExTractor "Log(Ex)Tractor.py"
  # результат: dist\LogExTractor.exe

Через GitHub Actions: workflow .github/workflows/release.yml собирает exe
на Windows и прикрепляет к релизу при его публикации (или вручную через
Actions → Build Windows exe → Run workflow, указав тег). Сейчас workflow
выключен; включить: gh workflow enable release.yml
